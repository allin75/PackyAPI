# 今日、昨日与累计排行榜

已获用户确认，先交付本地预览，确认后再提交和部署。

## 展示

夜间赛道风格、青绿灯带、金银铜领奖台，冠军居中。保留亮暗主题、用户名末字头像和小屏领奖台。顶部三个切换项：今日（默认）、昨日、累计。显示统计日期、有效参榜人数、该榜合计、更新时间和适用的名次变化说明。无数据的账号保留在列表中，显示暂无数据，不授予名次或放入领奖台。有效零用量正常参与排名。

## 数据口径

- 今日按北京时间日历日期显示，昨天23点快照到本次查询的差值；今天23点后使用当天结算记录，23点之后的消费归次日。未完成结算时最多保留今天的上一轮并标记旧数据，不纳入23点后实时消费。午夜自动切日期，不使用前一天的排行作兜底。
- 昨日读取昨日 daily_used，名次与前天在当前参榜账号集合下的排名比较；没有有效前天数据时没有升降信息。
- 累计沿用现有接口行为，累计已用金额并非永久历史总消费，周期重置会下降。
- 缺失基准不拿多日前记录做差。月度重置沿用现有 reset_adjusted 规则并标记周期调整；失败不阻塞其他账号。
- 只包含当前主动加入排行榜的账号。公开接口只含姓名、金额、名次与状态，不返回账号ID、剩余额度、密钥或私有周历史。

## 接口与存储

GET /api/leaderboard?period=today|yesterday|all，省略 period 保持旧累计接口兼容，非法值返回400。新榜返回 period、date、generatedAt、nextRefreshAt、settled、accounts。每行返回 name、used（可空）、rank（可空）、rankChange、movement、stale、usageStatus。

今日复用现有5分钟账号缓存和整点请求驱动策略。同轮请求合并，切换到累计不重复请求有效缓存。昨日只读库，不增加上游调用。加入/退出立即使今日快照失效，刷新期间变动也不泄露已退出账号。

数据库升级至5，增加一行今日排行状态（日期、生成时间、过期时间、快照JSON），保存最新一轮以支持重启后名次延续。保持现有累计快照和每日历史表，昨日通过历史数据即时计算，不新建无界增长的榜单历史。读出JSON按当前参榜账号过滤。
